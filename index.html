⚙ Connect Firebase

This build is wired for Firebase Auth + Firestore, but needs your project's config to run. Steps:

1. Create a project at console.firebase.google.com
2. Enable Anonymous sign-in under Authentication → Sign-in method
3. Create a Firestore database (production mode)
4. Copy your web app config into the firebaseConfig object near the top of the <script type="module"> block below
5. Paste the security rules from the comment above firebaseConfig into Firestore Rules

This overlay only shows because the config still has placeholder values — it disappears automatically once real keys are in place.
